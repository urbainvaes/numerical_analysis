# Typst version of the lecture notes

All chapters of the NYU version are converted (see PROGRESS.md for what remains).

## Building

From this directory:

    make                  # ../build/notes/main.pdf and one PDF per chapter
    typst watch main.typ  # main.pdf next to main.typ, rebuilt on every save

Requirements: Typst ≥ 0.14, Python 3 and `qpdf` (to split the book into
chapters), and the fonts below. The Typst package `@preview/fontawesome` is
downloaded automatically on the first build.

## Fonts

The fonts are those of the LaTeX version, and must be installed as system fonts:

| Font                                  | Used for                      | Arch package           |
|---------------------------------------|-------------------------------|------------------------|
| Latin Modern Roman, Sans, Mono, Caps  | text, headings, code          | `otf-latin-modern`     |
| Latin Modern Math                     | equations                     | `otf-latinmodern-math` |
| Font Awesome 7 Free                   | icons of exercises, sections  | `otf-font-awesome`     |

    sudo pacman -S otf-latin-modern otf-latinmodern-math otf-font-awesome

`typst fonts` lists the fonts that Typst finds.

## Layout

- `main.typ`: structure of the book (equivalent of `main.tex`);
- `template.typ`: styles and macros (equivalent of `preamble.tex` and `macros.tex`);
- `frontmatter/`, `mainmatter/`: the chapters;
- `csl/`: bibliography style approximating biblatex's `trad-abbrv`
  (`fullcite.csl` and `number.csl` are generated by `make_variants.py`);
- `julia.tmTheme`: syntax colors of minted's default style;
- `figures`, `references.bib`: symlinks to the shared files at the top of the repository
  (the LaTeX version of the notes is kept in `../backup`);
- `CONVERTING.md`: conventions for converting LaTeX to Typst.
